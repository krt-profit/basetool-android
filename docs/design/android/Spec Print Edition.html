Das Kartell / Bereich Profit

Profit Basetool // Android

UI design specification — Kotlin · Jetpack Compose · Material 3 · minSdk 29, target 37 · dark-only, DE-first

Print edition v0.1 · 17.08.2026 · This document carries the tokens, rules and per-screen redlines. The interactive mockups (phone 412×915 + tablet 1280×800, all states) live in the spec chapters 00–14 of the design project; this paper never replaces them. Print rendering uses dark-on-white for legibility — the app itself is dark-only.

1 · Decisions (binding)

Navigation. Phone: bottom bar with 5 destinations — Übersicht, Einsätze, Aufträge, Lager, Mehr. Tablet: rail with 7 + „Mehr", list-detail panes. Each destination keeps its own back stack; back on a root → Übersicht; predictive back everywhere.
Action hierarchy. The filled orange CTA marks the ONE primary action per context. Square 56 dp FAB on list screens; bottom-anchored 48 dp CTA bar on forms/details. Ladder: CTA → filled-green success → orange outline → ghost → quiet-danger.
Density & motion. Dense web-near lists (rows ~56 dp), touch targets ≥48 dp, 200 ms color transitions only, reduced motion honored. Countdowns relative („in 2 Std.").
Copy. German-first, military-terse, UPPERCASE labels, no emoji. „Einsätze" (nie „Missionen"), „Bereich Profit" as org context, „Administration" (nie „Führung"). Error states in-fiction (EN canon) + one plain German helper line.
Auth. Keycloak via Custom Tab (never WebView) + optional Discord (fail-closed guild gate) + guest browse. Approval-pending and terms screens block the app. Custom KRT lock screen behind BiometricPrompt; FLAG_SECURE app-wide.
Offline. Cached-data banner (timestamp) pinned under the top bar; rows get a „Cache" chip; write actions disable at 45% — no offline queueing of mutations (append-only ledgers must not fork).

Shapes: every M3 slot 0 dp; pills 999 dp + circular radio/spinner/presence are the only rounded elements; status dots SQUARE 8 dp. Spacing scale 4/8/12/16/24/32 dp; touch ≥48 dp; tablet content ≤1200 dp; prose ≤80 ch. Depth = hairlines + orange corner brackets + bloom (focus 0 0 5 dp @30%, modal/CTA 0 0 20 dp @20%) — no soft drop shadows, ripple white 8% bounded square. 3 · Component canon (digest — states in ch. 02)

Buttons ladderRule
Filled CTAOrange fill, BLACK text, bloom on press — max ONE per screen context (Anmelden, Speichern)
Filled successGreen #239E33, white text — state changes (Check-In)
Orange outlineEmphasized secondary (Crew zuweisen)
GhostNeutral hairline → orange on press — routine repeated actions
Quiet dangerGray → red on press — destructive, always confirms with named consequence
Icon button48×48 dp, only for repeated universal row actions; ALWAYS contentDescription + tooltip
Buttons metric. Height 48 dp, padding 0/20, label 13 sp Bold +0.03 em UPPERCASE, icon 16 dp gap 8. Disabled = 45% opacity. CTA focus ring white; others orange 2 dp offset 2.
Containers. HUD box (hairline + rgba(20,20,20,.5) + 10 dp brackets TL/BR) = hero container, max 1–2 per screen. Card / --inset / --accent (3 dp orange top). Panel header: #1C1C1C + 4 dp orange left bar.
Status. Squadron badge = the ONE pill (orange ring). Chips squared 11 sp UPPERCASE (primary/success/danger/warning/info/muted/data). Status pill = square 8 dp dot + tint text: Geplant info · Aktiv success · Briefing warning · Abgeschlossen gray · Abgesagt danger.
Rows & tables. Dense rows min 56 dp, press #282828, selection = 3 dp orange inset + orange check (long-press). Tablet keeps tables (head #1C1C1C, 2 dp orange rule, zebra 2%); phone collapses to key-value cards — never horizontal page scroll. Numerics right + tabular.
Forms. Fill #1C1C1C, hairline, radius 0, height 48 dp, focus = orange border + bloom; labels neutral #D2D2D2 bold (never orange); errors #F2564B + warning icon; orange-chevron selects, square orange checkbox (black check), circular radio; combobox type-to-filter, active option orange bg/black text.
Overlays. Modal: #141414, 3 dp orange top edge, 13 dp brackets, 20 dp bloom, ONE filled CTA right + ghost cancel; danger variant red; type-to-confirm only for wipe-grade actions. Bottom sheets: shape 0, 3 dp orange edge, drag-handle pill. Toast: near-black + brackets + bloom, uppercase orange title; error red. Never native dialogs.
Feedback. Loading = orange ring spinner + UPPERCASE label. Empty = dashed border, short reason, exactly ONE action. Presence pill pulses, never blocks input; „Aktualisierung verfügbar" pill floats above the CTA bar. Pagination: „Mehr laden — X von Y" + ENDE DER LISTE marker.
KPI. Value white Bold tabular on dark chip; totals get 4 dp orange left bar; deltas in text tints; sparkline = drawn polyline, no chart library.

Tablet rail88 dp rail: Übersicht, Einsätze, Aufträge, Lager, Hangar, Raffinerie, Börse + Mehr; KRT mark top, Einstellungen bottom; list-detail panes (380–400 dp list)
Top app bar64 dp, #141414, 2 dp orange bottom rule; title orange Bold UPPERCASE; bell + unread badge; squadron context pill (tap = org switcher sheet). Pushed screens: back arrow, no bottom bar swap
  • Predictive back everywhere; 200 ms fade/slide transitions; re-tap active destination pops to root + scrolls top
  • Back on a destination root → Übersicht; on Übersicht → exit (no „press again" toast). Sheets/dialogs close first; dirty forms intercept once („Änderungen verwerfen?")
  • Deep links: push → target screen; cold start synthesizes back stack (target + Übersicht); das-kartell.org App Links via assetlinks.json; unknown route → 404 in-fiction
  • State survives navigation + process death (SavedStateHandle): scroll, filters, active tab (?tab=)

5 · Screen handoffs (mockups: chapters 04–13)

04 Auth

  • Login: mark + radial bloom (auth-only), CTA Anmelden → Custom Tab (toolbar #141414), Discord ghost, guest link, Fan Kit band, legal + server-status footer. Offline: login disabled 45% + banner
  • Approval pending: NO filled CTA (outline refresh + quiet logout), 60 s poll + push; Terms: sticky checkbox + CTA (disabled till checked), decline = confirm logout; Lock screen: no data hints while locked

05 Übersicht (Dashboard)

  • Order: greeting → announcement (collapsible, mark-read) → Einsätze ≤7 Tage (whole card tappable, relative countdown + TS time, „Meine Einheit" chip) → 4 Schnellaktionen (Check-In, Einbuchen, Auftrag, Angebot) → unread preview

06 Einsätze & Operationen

  • Liste: segment Einsätze/Operationen, chip filters (sheets), date grouping, unit badge only in „Alle" mode, FAB 56 dp (Manager)
  • Detail: pinned head + facts bar (TS/Join/Ort/Leiter) + 7 tabs (Übersicht, Teilnehmer, Einheiten, Ablauf, Ziele, Frequenzen, Finanzen), ?tab= deeplink; ONE bottom CTA: Anmelden → green Check-In → ghost Check-Out; Einsatz-Briefing = fixed 6-field kv (Ziel, Teamspeak, Serverjoin, Treffpunkt, Dauer computed, Einsatzleiter); attendance open-ended (count + eingecheckt meter, no slots)
  • Anmelden sheet: payout radios (Auszahlung / Verzicht Org-Kasse) + optional ship; Finanz-Eintrag: sign from Typ segment, never typed; Operation: rollup + my payout status badge + manager toggles (asymmetric gate: mark instant, unmark confirms)

07 Benachrichtigungen

  • Unread = 3 dp orange bar + bold + orange type icon; swipe right gelesen / left löschen (commit ≥50%, undo toast 5 s, buttons remain for AT); newest 50 + „Mehr laden"; row tap deep-links; poll + SSE

08 Hangar

  • Cards: Typ + „Name", chips Versicherung/Fitted, Ort; edit 44 dp; segment Meine/Org-Einheit (KPI tiles + per-type breakdown); overflow: Home-Location, Import, Hangar leeren (count-naming danger modal); Fleetview import: file/paste → result modal (Importiert/Nicht erkannt/Duplikate)
  • Manufacturer marks: lettermark placeholders — repo white SVGs (Anvil/Drake/MISC) embed rasters; devs must re-export clean vectors

09 Lager & Blueprints

  • Tree: Material (orange rail) → Stack (gray rail) → Eintrag (dark inset); one header, quality mini-gauge 0–1000, amounts bright + dim unit; long-press bulk Umbuchen; collapse state persisted
  • Buchen: segment Ein-/Aus-/Umbuchen (Ausbuchen warns append-only; Umbuchen adds target); Zuordnung = Variante C/Modell G: two independent splits (Aufträge orange / Einsätze blue) with amounts, live Rest chip (0 success · frei muted · überbucht danger + save locked); personal entries carry no association
  • Blueprints: craftability chip + missing-materials breakdown; batch import file → match preview → apply; tablet master-detail with per-ingredient quality slider (live ×-factor on mapped stats only)

10 Aufträge & Materialbörse

  • Queue: Prio + #ID + Art chip + status pill + Für/Durch badges + collapsible materials w/ progress; age tint >30 d yellow, >90 d red; drag-reorder Logistiker only (long-press, overflow fallback)
  • Detail: facts (Für/Durch/Zuständig) + 4 tabs (Positionen, Materialbedarf — queue-gated fold, Übergaben + „Übergabe erfassen" CTA, Verlauf read-only); status change via sheet with named consequence
  • Börse: segment Angebote/Gesuche; „Ich kann liefern" toggle (retractable, creator sees list); Gesuch: Menge + optional Min-Qualität; handover/location stay off-tool; own entries: edit + withdraw

11 Raffinerie

  • Orders: status In Arbeit (countdown, minütlich) / Abholbereit (push) / Eingelagert; yield lines + est. value (data white/green, never orange); Extractor-JSON import (approved clients only, §4 terms)
  • „In Lager buchen": creates one Lager entry per material with quality + source ref, marks order eingelagert, CTA disables after

12 Bank

  • Tabs Konten/Anträge; KPI total + account cards w/ drawn sparkline; CARTEL visible to all, others per view grant
  • Detail: balance hero, custody holder bars (sum = balance), transactions (+/− tints), Kontoauszug PDF; Antrag: Typ segment, approval-ladder hint under amount (≥100 k → 2 Freigaben), never self-approve; ledger append-only — no offline queueing

13 Beförderung & Einstellungen

  • Beförderung: rank hero, 5 requirement rows w/ progress, matrix Selbst/Leitung/Ziel (below-goal yellow), read-only for members
  • Einstellungen: Sprache DE/EN segment, App-Sperre (SQUARE toggle, BiometricPrompt on enable), Blueprint-Sharing, Auszahlungspräferenz, aktive Org-Einheit, Rechtliches + Fan Kit band, „Lokale Daten löschen" (danger modal, server data untouched), Abmelden, version/server-status footer

6 · System states & app icon

  • Offline: banner (wifi-off, warning bar, „Zuletzt aktualisiert …") + Cache chips; reconnect flips green 2 s then auto-refresh
  • 409: „Konflikt festgestellt" modal — reload CTA, inputs preserved; 429/503: full-screen only on first load — countdown in the ring spinner, backoff 3/6/12/30 s, 429 uses Retry-After; Forced update: blocking screen, installed→required chips, CTA Play Store
  • Errors (in-fiction canon): 403 „Access Denied — Insufficient security clearance. This incident has been logged." · 404 „Signal Lost…" · 500 „System Malfunction…" · CTA „Zurück zur Basis"
  • Push: small icon = alpha-only monochrome mark, accent #E77E23, ≤2 uppercase actions, channel set (Einsätze & Check-In, Aufträge, Börse, Bank, System), sensitive amounts never on the lock screen
  • Adaptive icon: foreground orange mark in 66/108 safe zone · background flat #000 · monochrome layer shipped deliberately (Android 13+ themed icons). Logo ONLY in #E77E23, white or black — hard rule
