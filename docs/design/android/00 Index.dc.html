Decision log

Navigation
Phone: bottom bar with 5 destinations (Übersicht · Einsätze · Aufträge · Lager · Mehr). Tablet: rail with 7 + „Mehr" menu, list-detail panes.
Primary action
Square 56 dp FAB on list screens; bottom-anchored 48 dp CTA bar on forms and detail contexts. Max one filled-orange action per context.
Mission detail
Sticky header + facts bar + scrollable tab row (web .tab-nav pattern carried over). 7 sections, deeplink ?tab=.
Density
Dense, web-near lists (rows ~56 dp) — touch targets never below 48 dp. Countdowns relative („in 2 Std."). No emoji, restrained motion (0.2 s).
Auth
Keycloak via Custom Tab + Discord entry (guild-gated). Approval-pending and terms-acceptance states. Custom KRT app-lock screen behind biometrics.
Offline & states
Cached-data banner with timestamp on every list + per-screen offline variants. In-fiction error copy. System-push mockups for notifications.
App icon
Adaptive icon: orange mark on black, monochrome layer for themed icons. Logo only in orange #E77E23, white or black.
Dev artifacts
Theme.kt (colorScheme/typography/shapes), HTML token sheet, icon SVG export list, handoff notes per screen.
