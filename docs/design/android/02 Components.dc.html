Component sheet

Compose components in every state. Default cells are live — hover and press them. Pressed/focus cells are forced for redlining. 1 px = 1 dp.
Global

All interactive heights ≥ 48 dp (web system uses 44 px — Android rounds up). Radius 0 everywhere except pills and circular radio/spinner/presence. Ripple: white 8%, bounded, square. Color transitions 200 ms. Disabled = 45% opacity, never a new color.
