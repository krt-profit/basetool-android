Handoff — DashboardScreen
  • Order: greeting → announcement (collapsed when read) → missions ≤7 d → quick actions → unread preview
  • Mission card = one tap target; no per-card filled CTA (web's „Einsatz öffnen" button becomes the row affordance)
  • Countdown relative („in 2 Std."), refreshed each minute; absolute TS time beside it
  • Quick actions fixed set of 4 (user pick): Check-In, Einbuchen, Auftrag, Angebot
  • Pull-to-refresh; announcement mark-read POSTs like the web (announcement/read)
  • Datenquelle: „{n} angemeldet" kommt aus der Teilnehmerzahl des LISTEN-Endpunkts — MissionListDto erhält das Feld (Eigentümer-Entscheidung 25.08.2026). Nicht aus dem Detail-DTO lesen; bis das Feld deployt ist, Zeile ausblenden statt Platzhalter
