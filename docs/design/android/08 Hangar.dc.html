6 · Hangar leeren — Danger-Modal (Auflösung 08.1 ↔ 08.3)

Hangar leeren?

Alle 3 Schiffe werden aus „Meine Schiffe" gelöscht. Kein Undo in der App — Wiederherstellung nur über erneuten Fleetview-Import. Einsätze, Aufträge und Lager bleiben unberührt.
Entscheidung — „Hangar leeren"
  • Widerspruch 08.1 („type-safe") ↔ 08.3 („Alle 3 Schiffe löschen?") aufgelöst: es gilt das Danger-Modal MIT Anzahl, OHNE Tipp-Hürde — 08.1 ist korrigiert
  • Begründung: Kap. 02 §7 reserviert die Tipp-Hürde für irreversible Admin-Aktionen auf organisationsweiten Daten (Wipe-Grade). Der persönliche Hangar ist eigene Daten und über erneuten Import wiederherstellbar — eine Tipp-Hürde hier würde die echte entwerten
  • Schutz dreifach: roter Menü-Eintrag → Modal nennt Anzahl + Konsequenz + Wiederherstellungsweg → CTA wiederholt die Anzahl
  • DELETE wartet auf den Server; Erfolg → Toast „Hangar geleert (3 Schiffe)." + leerer Zustand
